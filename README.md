# COG Explorer

## Application description

GISAT's internal application for checking validity of Cloud Optimized GeoTIFF.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## COG Styling

COG url sample:

